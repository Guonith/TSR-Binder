# TSR-Binder
Биндер с прикольными фишками для игроков. Ориентирован больше на старший состав и замов/лидеров.
Имеет следующие функции:
- Шпаргалка
- Заметки
- Логи
- Быстрый ответ /d
- Smart-Invite (Поэтапное собеседование по стандартной команде /invite ID_Player)
- Биндер
- Авто-MSG
- Учет отыгранного времени
- Авто-отыгровки /mask, /time, /armour, и переключения между оружием.
- Смена между встроенными темами
- Создание собственных кастомных тем.

### В планах реализовать:
- ИИ агент помогающий с ответами в чат.
- Гибкость Smart-Invite
- Увелечение вещей в логирование

**Инструкция по установке:**
*1. Качаете файл с Releases*
*2. Открываете папку с игрой (По умолчанию это: C:\Users\User\AppData\Local\Programs\Arizona Games Launcher\bin\arizona\)*
*3. Закидываете .lua файл, скачанный ранее в папку **moonloader***
*4. Заходите в игру, настраиваете под себя.*
*5. Готово.*
   После всех настроек в папке moonloader будет автоматически создана папка **TSR-Binder** где будут храниться все файлы с данными ваших настроек.
Основные это: **tsr_binds.json**, **tsr_auto.json**, **tsr_frac.json**, **tsr_notes.json** и **tsr_cheatsheet.txt**(*не бойтесь названия, с англ. это шпаргалка.*).
Так же если вы будете настраивать Авто-отыгровку /time, появится файл **tsr_timexp.json**, в нем хранятся настроенные отыгровки /time,
в **tsr_time.json** хранятся данные об отыгранном времени за неделю(*Time Statistic*), в **tsr_theme.json** хранится строчка данных с запоминанием темы которую вы выбрали, 
если это кастомная тема там будет значение более 4.
Для тех кто 7+ ранг, повится файл **tsr_delivlog.json** и **tsr_radio.json** это файлы данных с вкладки логов.
И для замов/лидеров т.е. 9/10 ранг это файл с данными Smart-Invite, **tsr_sinvite.json**, в файле хранятся данные об настроенных этапах собеседования.
Для тех кто будет создавать кастомные темы - ваши кастом темы кидать в эту же папку, экспорт тем происходит в эту же папку, это сделано для удобства, и чтобы не засорять основную папку moonloader.
